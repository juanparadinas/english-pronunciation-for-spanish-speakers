# English Pronunciation for Spanish Speakers

A structured guide to English (SSBE) pronunciation for native Spanish
speakers — phonemes, spelling-to-sound rules, stress, and the hidden rules
nobody teaches.

This is the published form of a personal teaching wiki. It is organised one
page per sound, in a two-angle format (letter → sound and sound → spelling),
and covers:

- Foundations: the phoneme inventory and the priority sounds for Spanish speakers.
- Vowels and diphthongs, one page per sound.
- Consonants not in Spanish (r, dark l, v, z, sh, th, etc.).
- Reading rules: spelling-to-sound, unwritten rules, silent letters, the
  letters A/U/OU, double consonants, R and W distortions.
- Stress and intonation, including noun/verb pairs.
- Reference: minimal pairs, homophones, British vs American, study links.

## Build and preview locally

This site uses [MkDocs](https://www.mkdocs.org/) with the Material theme,
managed with [uv](https://docs.astral.sh/uv/):

```bash
uv sync
uv run mkdocs serve
```

Then open http://127.0.0.1:8000.

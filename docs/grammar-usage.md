# Grammar and usage (common Spanish errors)

> Not pronunciation, but the recurring grammar and collocation errors that
> Spanish speakers carry into English. Kept here so the resource covers the
> whole "sounds wrong" surface, not only phonetics.

## Collocation and preposition errors

| Wrong | Right | Note |
|---|---|---|
| worth to + infinitive | worth + gerund | it's worth doing, not "worth to do" |
| have sense | make sense | |
| I am agree | I agree | "agree" is a verb, not an adjective |
| responsible of | responsible for | |
| people is | people are | "people" is plural |
| related with | related to | |
| take a decision | make a decision | |
| for me (to request) | to me (recipient) vs for me (benefit) | distinguish |
| any question | any questions | plural after "any" here |

## at the end vs in the end

- at the end (of something) = position: "at the end of the film".
- in the end = finally, after everything: "in the end, we agreed".

Reference: languagetool insights article (in [study links](study-links.md)).

## used to vs usually

- used to + infinitive = past habit no longer true: "I used to smoke".
- usually = present habitual: "I usually walk to work".

## I / me / myself

- I = subject: "I did it".
- me = object: "give it to me".
- myself = reflexive/emphatic: "I did it myself"; not a fancy "me".

## Verb agreement traps

people are, the news is, information is (uncountable), everybody is.

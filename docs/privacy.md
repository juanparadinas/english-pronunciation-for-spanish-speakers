# Privacy

This site does not use cookies and does not collect personal data.

## Analytics

The site uses [GoatCounter](https://www.goatcounter.com/), a privacy-friendly,
open-source analytics tool:

- No cookies are set in your browser.
- No personal data is stored; data is anonymous and aggregated.
- No cross-site or individual tracking.

GoatCounter counts page views to give a rough idea of which pages are useful.
It does not identify you.

## Hosting

The site is served by GitHub Pages. As with any web host, GitHub may process
standard server request data (such as IP addresses) for security and
operational purposes; see GitHub's own privacy documentation for details.

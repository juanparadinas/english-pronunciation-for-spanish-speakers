# Homophones

> Words spelled differently but pronounced the same. English has many, partly
> because of silent letters, vowel-team overlaps, and (in SSBE) non-rhoticity,
> which erases final-R distinctions. Useful for listening, spelling, and
> appreciating how far spelling drifts from sound.

## Non-rhotic (British) homophones

In SSBE the final R is not pronounced, so these merge in British English but
usually stay distinct in rhotic American:

| Set | SSBE pronunciation | Distinct in US? |
|---|---|---|
| paw / pour / poor | /pɔː/ (for many speakers) | yes |
| saw / sore / soar | /sɔː/ | yes |
| court / caught | /kɔːt/ | yes |
| father / farther | /ˈfɑːðə/ | yes |
| formally / formerly | /ˈfɔːməli/ | yes |
| wander / wonder | close, not exact | — |

## Accent-dependent near-homophones (yod coalescence)

In relaxed SSBE, /dj/ and /tj/ coalesce to /dʒ/ and /tʃ/, which merges some
words that are distinct in careful speech:

| Set | Careful | Coalesced (casual SSBE) |
|---|---|---|
| dual / duel / jewel | /ˈdjuːəl/, /ˈdjuːəl/, /ˈdʒuːəl/ | all -> /ˈdʒuːəl/ |
| due / dew / Jew | /djuː/, /djuː/, /dʒuː/ | due/dew -> /dʒuː/ = Jew |
| tune / (a) choon | /tjuːn/ | -> /tʃuːn/ |

So "dual", "duel" and "jewel" can all sound identical in casual British speech,
even though "jewel" starts from a different spelling. This is yod coalescence,
the same process that gives nature /ˈneɪtʃə/ and education /edʒuˈkeɪʃn/. See
[connected speech](connected-speech.md) and [the letter U](letter-u.md).

## Why so many homophones

- Silent letters collapse distinctions: know/no, hour/our, write/right.
- Vowel teams overlap: meet/meat, sea/see, plain/plane.
- Non-rhoticity (SSBE) erases final-R contrasts: paw/pour, saw/sore.
- Yod coalescence merges /dj, tj/ pairs in casual speech: dual/jewel.

## Common Spanish error

> Not an error so much as a listening and spelling challenge: a single sound
> can map to several spellings. Context disambiguates in speech; spelling must
> be learned per word.

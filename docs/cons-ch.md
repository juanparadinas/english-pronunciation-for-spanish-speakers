# Consonant: /tʃ/ (CH)

> Producible for most Spanish speakers (it exists in Spanish "ch"), but the
> spellings that hide it, and the contrast with /ʃ/, need attention.

## 1. What it is

/tʃ/ is a voiceless postalveolar affricate: a /t/ immediately followed by /ʃ/,
as in "church", "watch", "nature".

Spanish contrast: Spanish has /tʃ/ (the "ch" in "chico"), so production is
easy. The issues are: which English spellings give /tʃ/ (not only "ch"), and
not confusing it with /ʃ/.

## 2. How to produce it

Stop the air with the tongue as for /t/ just behind the ridge, then release
into /ʃ/. One quick sound, not two.

## 3. Angle 1 — spellings that make /tʃ/

| Spelling | Examples |
|---|---|
| ch | church, cheese, much, teach, chair |
| tch | watch, match, kitchen, catch |
| t (in -ture, -tu-) | nature, future, culture, question, actual |
| ti (some) | (compare /ʃ/ in -tion) |

## 4. Angle 2 — where the /tʃ/ sound is written

ch: church, cheese, much, teach, chair, child, rich, each.
tch: watch, match, kitchen, catch, fetch, switch.
t + ure/u: nature, future, culture, adventure, picture, question, actual,
virtual, situation (yod -> /tʃ/ by assimilation).

## 5. Minimal pairs / contrasts

| Pair | Contrast |
|---|---|
| chair / share | /tʃ/ vs /ʃ/ |
| cheap / sheep | /tʃ/ vs /ʃ/ (and vowel) |
| chop / shop | /tʃ/ vs /ʃ/ |
| catch / cash | /tʃ/ vs /ʃ/ |
| choose / shoes | /tʃ/ vs /ʃ/ |

## 6. Common Spanish error

> The trap: not knowing -ture and -tu- give /tʃ/ (nature, culture, actual),
> and softening /tʃ/ into /ʃ/.
> The fix: keep the /t/ stop at the start of the sound. Learn the -ture
> pattern. Contrast chair/share.

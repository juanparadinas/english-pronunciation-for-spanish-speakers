# Vowel: /æ/ (front a)

> Not a major problem for Spanish speakers: the Spanish "a" is already fairly
> front, so /æ/ (cat) is close enough. The hard one is the long back
> [/ɑː/](vowel-long-a-back.md). Still worth separating /æ/ from /ʌ/ and /e/.

## 1. What it is

/æ/ is a short, open, front vowel, between Spanish "a" and "e". It is the vowel
in "cat", "bad", "trap". In SSBE it is a flat, fairly open sound; in American
it is often more diphthong-like (/eə/) and more nasal.

Spanish contrast: Spanish has no exact /æ/, but the Spanish "a" is fairly
front, so /æ/ is one of the easier non-Spanish vowels. The minor risk is
drifting toward /ɒ/ (cat -> cot) or merging with /ʌ/ and /e/. The genuinely
hard back vowel is [/ɑː/](vowel-long-a-back.md).

## 2. How to produce it

Open the mouth as for Spanish "a", then move the tongue forward and slightly up
toward "e", and spread the lips a little. Short. It should feel like an "a"
leaning toward "e".

## 3. Angle 1 — when a spelling makes /æ/

Almost always a written "a" in a closed, stressed syllable.

| Spelling | Examples |
|---|---|
| a (closed syllable) | cat, bad, trap, hat, man, map, back, apple, random |
| a (closed, multi-syllable) | contract, impact, diagram, artifact, abstract |

## 4. Angle 2 — where the /æ/ sound is written

/æ/ is essentially always a written "a" in a closed syllable:

cat, bad, trap, hat, man, map, cash, back, apple, random, contract, impact,
diagram, transition, artifact, blackboard, abstract.

TRAP-BATH caveat (UK): some closed-"a" words take long /ɑː/ in SSBE instead
(past, path, class, last, dance). In American those stay /æ/. See
[the letter A](letter-a.md).

## 5. Minimal pairs / contrasts

| Pair | Contrast |
|---|---|
| hat / hot | /æ/ vs /ɒ/ |
| cat / cut | /æ/ vs /ʌ/ |
| bad / bed | /æ/ vs /e/ |
| ran / run | /æ/ vs /ʌ/ |
| cap / cup | /æ/ vs /ʌ/ |
| bat / bet | /æ/ vs /e/ |

## 6. Common Spanish error

> The trap: using the back Spanish "a", so cat sounds like "cot".
> The fix: push the tongue forward toward "e" and spread the lips. Contrast
> with /ʌ/ (cat/cut) and /ɒ/ (hat/hot) to place it correctly.

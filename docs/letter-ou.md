# The letters OU (two angles)

OU is the most unstable vowel team in English: around 11 different
pronunciations. There is no single rule; each word is learned. This page lists
them both ways so the patterns are at least visible.

## Angle 1 — how written 'ou' is pronounced (all 11)

| Sound | Examples |
|---|---|
| /ʌ/ | enough, young, couple, touch, rough, encourage, country |
| /ɒ/ | cough, trough |
| /ɔː/ | course, court, four, source, your, board, bought, brought, ought, thought |
| /ʊ/ | could, should, would |
| /uː/ | group, soup, route, through |
| /ɜː/ | journey, journal |
| /ə/ | famous, nervous, dangerous (unstressed -ous) |
| /aʊ/ | sound, house, loud, mount, mouse, out, announce, doubt, around, south, count |
| /əʊ/ | although, shoulder, soul, dough |
| /ʊə/ | tour |
| /aʊə/ | our, hour, flour, sour (ou + r) |

## Angle 2 — grouping by the resulting sound

- Most common everyday value is /aʊ/ (out, house, sound).
- Before -ght, OU is almost always /ɔː/ (thought, bought, ought).
- -ous suffix is always the weak /ə/ (famous, dangerous, nervous).
- A small fixed set is /ʊ/: could, should, would.
- Function/short words vary: you /uː/, your /ɔː/, young /ʌ/.

## Practical approach

1. Learn the fixed subsets: -ought/-ought = /ɔː/; -ous = /ə/; could/should/
   would = /ʊ/.
2. Default an unknown stressed OU to /aʊ/ (out, house), the most frequent.
3. Memorise the /ʌ/ group (enough, young, touch, country), a common trap for
   Spanish speakers who say /u/.

## Common Spanish error

> The trap: reading OU as a Spanish "ou"/"u", so "country" = "coun-tri" with
> /u/, or "enough" with /u/.
> The fix: there is no single value. Learn the subsets above; the /ʌ/ group
> (enough, young, couple, touch, country) is the highest-value fix.

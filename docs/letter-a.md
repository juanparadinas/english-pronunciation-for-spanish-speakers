# The letter A (two angles)

The key skill is to look at the letter A from both directions: given the
written 'a', which sound; given a phoneme, which spellings produce it. The
letter U gets the same treatment in
[spelling-to-sound rules](spelling-to-sound-rules.md).

## Angle 1 — how a written 'a' is pronounced

| Context | Sound | Examples |
|---|---|---|
| Closed syllable | /æ/ | cat, bad, trap, hat, apple, random |
| Open syllable / Magic e | /eɪ/ (alphabet a) | make, rate, late, able, basic, nation |
| a + R (stressed) | /ɑː/ (UK); /ɑːr/ (US) | car, start, far, hard, park |
| a + R + e / a + ir | /eə/ (UK); /er/ (US) | care, fair, chair, air, stare |
| a before l (often) | /ɔː/ | call, tall, walk, talk, salt, false |
| a + W / a + U | /ɔː/ | law, saw, cause, author, launch |
| Unstressed | /ə/ schwa | banana, about, alarm, america, academy |
| Many words (UK only) | /ɑː/ long a | past, path, class, last, fast, bath |

**TRAP-BATH split**: words like past, path, class, last, dance take long /ɑː/
in SSBE but /æ/ in General American. This is the single biggest UK/US
difference for the letter A.

## Angle 2 — where the /æ/ sound is written

Almost always a written 'a' in a closed syllable:

cat, bad, trap, hat, man, map, cash, back, apple, random, contract, impact,
diagram, transition, artifact, blackboard, abstract.

Note (UK): some closed-'a' words move to /ɑː/ instead (past, path, class). In
American they stay /æ/.

## Angle 2 — where the /ɑː/ (long a) sound is written

| Spelling | Examples |
|---|---|
| a + R | car, start, far, hard, park, large, March |
| a (UK TRAP-BATH) | past, path, class, last, fast, bath, dance, chance |
| al + consonant (silent l) | calm, palm, half, calf |
| foreign / misc | father, drama, banana (final), tomato (UK) |

## Angle 2 — where the /eɪ/ sound is written (not only 'a')

| Spelling | Examples |
|---|---|
| a (open / magic e) | make, late, able |
| ai | brain, rain, straight |
| ay | day, stay, play |
| ei | eight, veil |
| ea (rare) | great, break, steak |
| ey | they, grey |

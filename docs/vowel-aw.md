# Vowel: /ɔː/ (the "aw" o)

> A long, rounded, mid-back vowel. The -aw/-au spellings always give this
> sound, never the Spanish "au".

## 1. What it is

/ɔː/ is a long, rounded, mid-back vowel, the sound in "thought", "law",
"caught", "north". Longer and more rounded than /ɒ/.

Spanish contrast: Spanish has no long rounded vowel like this. Spanish speakers
read "au" as a Spanish diphthong (a + u), which is wrong.

## 2. How to produce it

Tongue mid-back, lips rounded, held long. More rounded and higher than /ɒ/.

## 3. Angle 1 — when a spelling makes /ɔː/

| Spelling | Examples |
|---|---|
| aw | law, saw, draw, dawn, awful |
| au | cause, author, launch, autumn, August, audio |
| or | short, port, cord, north, sort, born |
| ou (+ght/r) | thought, bought, brought, ought, course, four, source |
| oor / oar / ar(w) | door, floor, board, war, warm |
| al (some) | all, call, tall, walk, talk, salt, false |

## 4. Angle 2 — where the /ɔː/ sound is written

aw: law, saw, draw, dawn, awful, lawn.
au: default, caught, taught, faulty, launch, cause, because, clause, pause,
australia, author, audience, august, autumn, audit, authorization, audio.
or: short, port, cord, north, sort, born, horse, morning.
ough/ought: thought, bought, brought, ought, nought.
our/oor/oar: course, court, four, source, your, board, door, floor.
al: all, call, tall, walk, talk, salt, false, bald.
war-: war, warm, ward, dwarf.

## 5. Minimal pairs / contrasts

| Pair | Contrast |
|---|---|
| caught / cot | /ɔː/ vs /ɒ/ |
| port / pot | /ɔː/ vs /ɒ/ |
| walk / woke | /ɔː/ vs /əʊ/ |
| saw / so | /ɔː/ vs /əʊ/ |
| short / shot | /ɔː/ vs /ɒ/ |

## 6. Common Spanish error

> The trap: reading au/aw as the Spanish diphthong "au" (a-u), so "cause"
> becomes "ca-use".
> The fix: one long rounded O sound. au = aw = /ɔː/. Note: American often
> turns this into a back /ɑ/ in many au words.

# Consonant: /ʃ/ (SH)

> Spanish speakers can produce it, but the problem is knowing which spellings
> hide it, far more than just written "sh".

## 1. What it is

/ʃ/ is a voiceless postalveolar fricative, the "sh" sound in "she", "mission",
"sure".

Spanish contrast: standard Spanish has no /ʃ/, though some regions do (Río de
la Plata, parts of Spain). The production is easy for most; the real problem is
recognising the many spellings that produce it.

## 2. How to produce it

Tongue bunched just behind the alveolar ridge, lips slightly rounded and
pushed forward, push voiceless air. Like "s" but with the tongue pulled back
and lips rounded.

## 3. Angle 1 — spellings that make /ʃ/

| Spelling | Examples |
|---|---|
| sh | she, ship, shoe, cash, finish |
| ti (in -tion) | nation, station, question, patient |
| ss (in -ssion) | mission, discussion, pressure |
| ci (in -cious/-cial) | special, delicious, social, ancient |
| si (in -sion after cons.) | tension, mansion |
| ch (French loans) | machine, cache, chef, champagne |
| s (before u) | sure, sugar, assure |

## 4. Angle 2 — where the /ʃ/ sound is written (word lists)

session, mission, machine, cache, she, musician, politician, pressure, assure,
impression, discussion, expression, permission, progression, transmission,
possession, transition, visualization, special, social, delicious, nation,
station, sure, sugar, chef.

## 5. Minimal pairs / contrasts

| Pair | Contrast |
|---|---|
| she / see | /ʃ/ vs /s/ |
| ship / sip | /ʃ/ vs /s/ |
| sheet / seat | /ʃ/ vs /s/ |
| shave / save | /ʃ/ vs /s/ |
| sham / Sam | /ʃ/ vs /s/ |

## 6. Common Spanish error

> The trap: not realising a word has /ʃ/ (nation, sure, special) and saying
> /s/ or /tʃ/ instead.
> The fix: learn the spelling triggers (-tion, -ssion, -cious, -cial, s+u,
> French ch). The sound itself is easy; recognition is the work.
